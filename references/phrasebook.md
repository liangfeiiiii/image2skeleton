# 词组库

按八段顺序排。同一格里的词可以互换，换的时候注意别把层级改掉。

## 定位

| 中文 | English |
|---|---|
| 围绕任意主题对象构建一张克制的展览视觉 | Build a restrained exhibition visual around any subject |
| 一张极简语录海报 | a minimal quote poster |
| 一张编辑式专题封面 | an editorial feature cover |
| 纵向九比十六 | vertical, 9:16 |
| 保持冷静、洁净、灰阶丰富 | keep it calm, clean and rich in grey |

## 分区与空场

| 中文 | English |
|---|---|
| 上方约五成半为高明度空场 | the upper ~55% is a high-key empty field |
| 横贯全幅的绝对水平硬边 | a hard horizontal edge running full width |
| 洁净、近乎无物的空场 | a clean, almost empty field |
| 从左上和下缘大幅越界 | breaking far past the left and bottom edges |
| 留白保持完整，不被主体侵入 | keep the empty area intact, uninvaded by the subject |
| 图底转换清晰 | a clear figure-ground switch |

## 主体

| 中文 | English |
|---|---|
| 主题对象转译为 | the subject is translated into |
| 垂直居中于画面中轴 | centred on the vertical axis |
| 长度约占画面高度三分之一 | roughly one third of the image height |
| 被那条硬边拦腰横切 | cut in half by that edge |
| 作为一枚干净的剪贴实体 | treated as a clean cut-out element |
| 跨过切口时透视与形变一律不变 | its perspective and shape stay unchanged across the seam |
| 主题对象保留可识别特征 | keep the subject recognisable |
| 近乎纪念碑尺度的粗粝实体 | a coarse mass at near-monumental scale |
| 从实体内部形成巨大的椭圆暗腔 | a large elliptical void opens inside the mass |

## 层级

| 中文 | English |
|---|---|
| 建立近、中、远三层深度 | build foreground, middle and background depth |
| 最前方保留一块失焦的深色碎片 | a soft-focus dark fragment sits closest to camera |
| 不削弱暗腔轮廓 | without weakening the void's silhouette |
| 由次要实体向上遮挡 | secondary masses rise up and occlude |

## 材质

| 中文 | English |
|---|---|
| 手工烧结般的哑光低反射表面 | a matte, low-reflection surface like kiln-fired clay |
| 布满细小孔隙、颗粒、凹坑与断口纤维 | pocked with fine pores, grains, craters and torn fibre |
| 质感来自真实微地形和光线 | texture comes from real micro-relief and light |
| 不叠加均匀噪点、胶片颗粒或旧纸污渍 | no uniform noise, film grain or aged-paper stains |
| 背光面迅速沉入暗部 | shadow sides fall quickly into darkness |
| 湿润反光的表面 | a wet, reflective surface |

## 光

| 中文 | English |
|---|---|
| 由右上方的柔和侧逆光勾亮边缘 | rim-lit from a soft back-side light at upper right |
| 厚实而不规则的边缘 | thick, irregular edges |
| 暗腔保持接近无细节的最深暗值 | the void holds near-detail-free maximum darkness |
| 主光只作用于主体，空场不受光 | the light reaches the subject only, never the field |

## 色彩

| 中文 | English |
|---|---|
| 维持近单色、低饱和、强明暗分区 | near-monochrome, low saturation, strongly zoned by value |
| 色彩由主题语义派生 | palette derived from the subject's meaning |
| 文字在深浅区域分别采用清晰反色 | type reverses clearly against light and dark zones |
| 仅用一个针尖般小面积、较暖且稍高饱和的方点 | a single pinhead-sized warm, slightly saturated square |
| 唯一的色彩停顿 | the only colour pause in the frame |
| 避免多色装饰与泛黄做旧 | avoid multi-colour decoration and sepia ageing |

## 文字

| 中文 | English |
|---|---|
| 主标题悬置于高亮空场 | the headline floats in the bright field |
| 采用细瘦、高对比的中文宋体骨架 | a thin, high-contrast Song-style skeleton |
| 两行等大的高对比衬线大写，行距压到几乎相触 | two equal lines of high-contrast serif caps, leading almost touching |
| 第三行是一枚细瘦手写体，向右越出第二行末端 | a thin script word overshoots the second line to the right |
| 竖向单字排列，字与字之间留出明显停顿 | stacked vertically, character by character, with visible pauses |
| 个别字降低明度，形成呼吸 | a few characters sit lighter, giving the block air |
| 右侧设置更小、更紧的竖排说明 | a smaller, tighter vertical caption to its right |
| 两组文字均避开实体边缘 | both text blocks clear the mass's edge |
| 展览信息沿暗区左下组织为窄列 | exhibition data forms a narrow column at lower left of the dark zone |
| 年份、日期、开放时间与场地逐级下行 | year, date, hours and venue step down in rank |
| 数字与汉字使用轻字重与宽字距 | light weight and wide tracking on both numerals and characters |
| 右下安置方形导览码与细窄竖注 | a square guide code and a narrow vertical note sit at lower right |
| 不誊抄原文，只保留板块结构 | do not transcribe wording, keep only the block structure |

## 收束

| 中文 | English |
|---|---|
| 第一眼必须形成粗粝巨物与洁净空场之间的压迫式对照 | the first read must be the pressure between a coarse mass and a clean void |
| 文字保持疏远、安静、可读 | type stays distant, quiet, legible |
| 不缩小实体 | do not shrink the mass |
| 不填满留白 | do not fill the empty field |
| 不照亮暗腔内部 | do not light the inside of the void |
| 不加倒影、尾迹或水面扰动 | no reflection, wake or water disturbance |
| 不加装饰性图形、边框与标志 | no decorative shapes, borders or logos |
| 不做斜面、不做立体 | no bevel, no 3D |

## 英文整段起手式

Create a restrained vertical poster around any subject, 9:16. A clean high-key field occupies the upper half; a hard, full-width horizontal edge separates it from a low-key lower zone. The subject is translated into ___, centred on the vertical axis, spanning roughly a third of the height, cut in half by that edge and holding its shape rigid across the seam. Type sits in the bright field, ___. The first read must be ___. Do not shrink the subject, fill the void, or add decoration.
