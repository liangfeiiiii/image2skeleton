# 八段写法与失效模式

每段给三样东西：这段负责什么、写到什么程度停下、写过了会长什么样。

## 一 定位句

负责：把成品类型、画幅、用途一次说清，让模型先站好位置。

写到：围绕任意主题对象构建一张什么样的成品，纵向还是横向，几比几。一句话够了。

失效：写“一张震撼的视觉海报”这种。类型词越虚，模型越爱自己加东西。

## 二 空场与分区

负责：明度骨架。大块留白是这张图最贵的部分，先把它钉死。

写到：几成高、几成暗，边在画面高度的哪个位置，硬边还是柔边，是否横贯全幅，留白是洁净的还是有极细颗粒。

失效：通篇不提留白，只在写主体。成品会把主体放大填满，这是最常见的走样。

失效：把边写成“约 54.7%”。没人需要这个精度，反而挤掉别的信息。

## 三 主体

负责：把原图的具体物转译成一个可替换的角色。

写法分两层。先说角色，例如“主题对象转译为一艘俯视的窄长木船”，换成鞋、乐器、瓶子、蛇都成立。再说占位：垂直居中于中轴，长度约占画面高度三分之一，宽度约占四分之一，正好被那条硬边拦腰横切。

“被切断”比“位于那里”有用得多。切断关系一写，尺度、位置、边线就全对上了。

失效：只写对象名字不写占位。模型会把它放在舒服的地方，通常是正中偏下、缩到六成。

失效：给主体加原图没有的三维感。“俯视”写成“略带俯角”，整张图就散了。

## 四 层级

负责：前中远三层，以及遮挡的先后。

写到：谁压住谁，最前面留一块什么质地的失焦物，遮挡有没有削弱主轮廓。

失效：只写“有前景”。不说清压住谁，模型会把前景塞在角落当装饰。

## 五 材质与光

负责：质感的来源。

写到：表面是手工烧结般的哑光低反射，还是湿润反光；纹理集中在受光面与边缘，背光面迅速沉入暗部；光从右上柔侧逆来，只勾亮边缘。

关键句式：质感来自真实微地形和光线，不叠加均匀噪点、胶片颗粒或旧纸污渍。这一句几乎能挡掉一半的廉价感。

失效：列一堆材质词（磨砂、拉丝、做旧）却不给光。材质词没有光就只是贴图。

## 六 色彩

负责：明度分区之外的色相策略。

写到：由主题语义派生，但维持近单色、低饱和、强明暗分区；深色实体覆盖大部，高明度空场形成对冲；文字在深浅区分别反色；全局只留一个针尖大的暖色点。

失效：写“高级灰”“莫兰迪色”。这类词是评价不是配方。

## 七 文字系统

负责：板块结构，不是文案。

四件事写清就够：位置与对齐轴、行数与行间关系、字形类别与相对字号、与主体的压叠或避让。

字号用“大、中、小、微”四级就够，再加一句相对关系，例如“日期明显大于说明文字”。

失效：写出“宋体”“思源黑体”。字体名会把模型引向具体字库，配不上就崩。写“细瘦、高对比的中文宋体骨架”即可。

失效：把每一行都数清楚。三行以上就别数了，写“三到四行、右端不齐”。

## 八 收束

负责：一句话把脾气定死，再用几个“不”封住岔路。

结构固定成两半。前半句说第一眼必须形成什么对照，例如粗粝巨物与洁净空场之间的压迫式对照。后半句连着三到四个否定，每个都针对这张图最可能跑偏的方向：不缩小实体、不填满留白、不照亮暗腔内部。

失效：只写正面要求不写否定。模型不缺想象力，缺的是禁令。

失效：把“不”写成“不要做得太差”这种没法执行的句子。

## 比例与位置词表

用这类词，不用数字：

| 想表达 | 写成 |
|---|---|
| 一半多 | 约五成半、略过中线 |
| 三分之一 | 约三分之一、不足四成 |
| 很窄的一条 | 窄列、细带 |
| 中间被切 | 腰部横切、齐腰截断 |
| 顶到边 | 上缘抵边、从下缘大幅越界 |
| 左上角 | 左上角、左上空场 |
| 底部一条 | 沿下缘铺开 |

## 关系动词表

越界、压边、悬置、横切、下沉、托起、对冲、遮挡、贯通、塌陷、收束、溢出、退进背景。

这些词比形容词有效。它们描述的是关系，模型能照着摆位置。
