<br>

**一个看图反推提示词的技能。给它一张参考图，它给回一段能直接喂给出图模型的提示词，锁的是构图骨架，不是像素细节。**

不是复刻，是把一张成品拆成一套可以反复套用的版式。

**双重取舍**：结构留住（分区、尺度、明暗、层级）+ 细节放手（文案、色值、字号都不写）。

## 效果示例

> 参考图是一张竖版极简海报：上半米白空场，下半深青水面，一条硬边横切全幅，一艘俯视木船垂直居中，正好被这条边拦腰截断。

喂进去的是一张图，吐出来的是这段：

```text
围绕任意主题对象构建一张克制的极简语录海报，纵向九比十六。上方约五成半为高明度、
洁净、几乎无纹理的暖白空场，向下以一条横贯全幅的绝对水平硬边直接切断，下半是低明度
的深青水面，波纹细密、对比很弱、边缘带柔，越往下越沉。主题对象转译为一艘俯视的窄长
木船，垂直居中于中轴，船首朝上，长度约占画面高度三分之一，宽度约占四分之一，正好被
那条硬边拦腰横切：船首悬在暖白里，船尾浸在深水中。这只船作为一枚干净的剪贴实体存在，
跨过切口时透视与形变一律不变，不产生倒影、折射、尾迹或水面扰动……
第一眼必须形成上轻下重、横向一刀两断的静默感，文字疏远安静，不填满留白，不加倒影，
也不把船画成斜视或立体。
```

注意里面没有一处原文、没有一个色值。想换主题，只动主体那一段：

```text
主题对象转译为一艘俯视的窄长木船
　　→ 主题对象转译为一双俯视的旧皮鞋，鞋头朝上，两只并排
　　→ 主题对象转译为一支俯视的长号，管口朝上
```

其余七段原样不动，版式还立得住。

## 快速开始

### 最省事：丢给 Agent

不用敲命令。把下面这句连同仓库地址发给你的 Agent：

```text
安装这个技能，装到全局技能目录：https://github.com/liangfeiiiii/image2skeleton
```

它会自己去 GitHub 拉代码、放进 `~/.dsh/skills/image2skeleton`。装完新开一个会话，技能就出现在列表里。

### 或者自己敲命令

```bash
# 克隆到全局技能目录
git clone git@github.com:liangfeiiiii/image2skeleton.git ~/.dsh/skills/image2skeleton
```

没配 SSH 密钥就换成 HTTPS：

```bash
git clone https://github.com/liangfeiiiii/image2skeleton.git ~/.dsh/skills/image2skeleton
```

<details>
<summary>Windows 下怎么放</summary>

在 Git Bash 里上面那行可以直接跑。用 PowerShell 的话，家目录要写全路径：

```powershell
git clone https://github.com/liangfeiiiii/image2skeleton.git "$env:USERPROFILE\.dsh\skills\image2skeleton"
```

不想用 git，就下载仓库的 zip，解压后把整个文件夹放到：

```
C:\Users\<用户名>\.dsh\skills\image2skeleton
```

新开一个会话，技能会出现在列表里。

</details>

## 功能特性

### 一遍读完的流程

| 步骤 | 做什么 |
|------|--------|
| 读图三问 | 画面被切成几块 / 谁压谁 / 哪一处是签名动作 |
| 四层账本 | 版式、主体、材质光、文字板块，分层记，不混写 |
| 八段编译 | 从定位句一路排到收束禁令 |
| 收口 | 一句定调，加三到四个"不" |

### 三条红线

1. **不誊抄画面文字**：只记行数、字形类别、对齐和压叠，不记具体词句
2. **不写色值、字号、像素**：用"约五成""三分之一""腰部"这类词
3. **不写看不见的东西**：不猜器材和字体出处，不补原图没有的道具

### 八段结构

| 段 | 负责 | 写到什么程度 |
|----|------|--------------|
| 一 | 定位 | 围绕任意主题对象构建一张竖版海报，九比十六 |
| 二 | 空场与分区 | 上方约五成半为高明度空场，一条横贯全幅的硬边 |
| 三 | 主体 | 转译为一艘俯视的窄长木船，被硬边拦腰横切 |
| 四 | 层级 | 近、中、远三层，最前面一块失焦碎片 |
| 五 | 材质与光 | 哑光低反射，右上柔侧逆光勾边，暗部迅速沉下去 |
| 六 | 色彩 | 近单色、低饱和、强明暗分区，只留一个色点 |
| 七 | 文字系统 | 两行高对比衬线大写，行距相触，第三行手写体越界 |
| 八 | 收束 | 第一眼必须形成什么，再接三个"不" |

### 附带的参考

- **八段写法与失效模式**：每段都写了"写过头会长什么样"
- **中英对照词组库**：越界、压边、悬置、对冲这些关系动词都在里面
- **两个完整示例**，外加一个反例拆解：过细的版本为什么不能用

## 目录结构

```
image2skeleton/
├── SKILL.md                      # 主流程：读图、四层账本、八段编译、红线与自检
├── manifest.json                 # 元信息
├── references/
│   ├── framework.md              # 八段细化写法与失效模式
│   └── phrasebook.md             # 中英对照词组库，按八段排
├── examples/
│   └── examples.md               # 两个完整示例，一个反例，换主题演示
└── README.md                     # 本文件
```

## 能改什么

想调成自己的口味，这几处最直接：

- **整体口气**：`SKILL.md` 顶上的"一条原则"
- **八段的详略**：`references/framework.md` 里每段的"写到"和"失效"两小节
- **补充词汇**：`references/phrasebook.md` 对应段落加行，中文一列英文一列
- **基准样本**：`examples/examples.md` 里的示例二，用来对标篇幅和抽象程度
- **触发条件**：`SKILL.md` frontmatter 的 `description`，决定什么样的请求会命中它

## 说明

本技能只产出文字提示词，不生成图片，不调用任何接口，也不读取凭据。成品质量取决于使用的手模对文字提示词的理解能力，纯文字重建无法保证像素、字形和随机纹理完全一致。
